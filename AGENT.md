Agent Guidelines

How to interact with the assistant for this project:

- Work in small, focused increments. Ask for one change at a time.
- Test-first: require tests for every new piece of functionality before code is provided.
- Do not add files, folders, or dependencies unless they are immediately used.
- Keep UI and code clean and professional; avoid AI-styled visuals or gimmicks.
- Performance: include benchmarks when relevant and keep regressions visible.
- Documentation: update `DEVELOPMENT.md` with decisions and rationale.
- Follow `PLAN.md` and ask questions.

Assistant responsibilities
- Create minimal, working code with passing tests.
- Run tests when producing code and report results.
- Produce short, actionable progress updates after changes.
